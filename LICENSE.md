# Licensing — the map

ADOPTED 2026-11-20 by the Director's approval of the
draft package. The split: the same three-layer split as
[Yellow Rav3n](https://github.com/c4chaos-io/yellow-rav3n)
and [Centaur Club](https://github.com/c4chaos-io/centaur-club),
for the same reasons: the anthology carries original
characters (Fluffy's likeness and voice) and original
writing the house wants protected, while its posts are
meant to be quoted and shared.

This file is the map; the layer files carry the terms.
When this map and a layer file disagree, the layer file
for that material governs, and flag the disagreement to
the author; do not silently pick one.

## On forks and copies

Forking is a GitHub platform mechanic, not a license.

- **A fork grants no rights.** Forking, cloning, or
  copying grants no right to use Core IP beyond the
  layer terms above.
- **A fork preserves the evidence.** A fork carries the
  commit history, timestamps, and origin attribution.
  It cannot backdate or reassign the record.
- **Enforcement follows use, not copying.** What is
  published here is finished work at web resolution;
  the raw voice logs, masters, and process material are
  never in this repository to be forked.
