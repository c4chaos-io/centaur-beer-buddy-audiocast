Rules that govern these files:

  C4's. Do not harmonize them after the fact.

  and labeled in the narration itself (standing rule,
  2026-11-12).
- A correction (EP04 v1 to v2 is the standing example) is
  made in a new version with the error named in the episode
  file, never by silently editing the shipped script.
